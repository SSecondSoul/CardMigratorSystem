## 原因与通用修正

1. 共享旧 class 语义检查器将条件字符串里的前导空格当成类名的一部分，不能识别 `base{{flag ? ' active' : ''}}` 与 `base {{flag ? 'active' : ''}}` 等价。现在先按原始字符验证 token 边界，再归一化类名空白；类名粘连、条件写反、丢失 token 仍失败。
2. 新 AST 投影把 San 整段三元插值的 `.segs` 当成文本分段，错误计入两个分支的文字；同时未恢复合并 class 中可识别的静态 token。现在明确区分表达式种类，修正固定 class 和相邻文本分段投影。v2 投影不证明条件表达式或任意方法等价，仍依赖语义／运行／场景检查。
3. 样式采集曾用 childNodes 序号作为元素路径，缩进空白会使相同元素错位。改为元素兄弟序号；非空文本仍进入 DOM 比较，没有忽略真实文本或节点差异。

新增结构路径／标签差异供修复诊断，旧模块实现指纹覆盖 Node 检查器。没有改生成／修复 Prompt、模型配置、修复预算、阈值或 UI 公式，也没有手改生成产物。
