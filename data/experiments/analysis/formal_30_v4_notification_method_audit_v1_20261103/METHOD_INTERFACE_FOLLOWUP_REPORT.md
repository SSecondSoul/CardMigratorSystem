## 保留范围和自动恢复边界

检查普通 Options 对象导出父组件的源业务方法，区分内联子组件和其它命名空间。支持直接方法、函数值，以及可静态解析且没有重新赋值的本地函数绑定。
同名公开包装方法可保留接口；仅把方法体改名并不证明原外部接口还在。San initData 的保留名冲突交由已有专用映射规则处理，不能覆盖状态工厂。
这里证明的是可调用面及受限恢复分支，不是所有已存在方法体、任意闭包、继承、动态分发或子组件 API 的完整行为等价。

自动恢复只允许：目标同名 option 完全缺失，源／目标内部均无已识别引用、引用覆盖没有不确定站点，签名和完整语句落在受限 AST 子集内。
只转换可确认的源／目标状态读取到 San data.get，保留参数、条件、返回和已理解调用的顺序。
外部自由变量、被遮蔽全局、动态 this／别名、写操作、复杂控制流、async／复杂参数、未知状态或依赖都不猜补。
已有非可调用／不透明 option 不覆盖；旧 Vue methods 包装先由既有解包规则处理，不往包装内外重复插入。
本地绑定支持不等于允许复制任意闭包，复杂依赖仍可能保留诊断或被候选门拒绝。

浏览器能力调用只有显式白名单和未被局部绑定遮蔽的形状可进入恢复；本次通知方法的原 capability 与 enabled 条件完整保留。
恢复只是定义方法，没有新增 saveSettings、mounted、watcher 或按钮触发点。
源无内部引用而目标新增显式引用时另报诊断；未知动态触发不宣称已经全面证明。
