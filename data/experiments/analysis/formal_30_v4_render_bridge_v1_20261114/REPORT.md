# 源码只读渲染桥接闭环 v1（2026-11-14，局部修复）

范围：只提升 Vue→San 源码迁移正确率，不实现 Ref provider、跨框架运行时互操作或其他额外功能。模型调用0；未启动服务器／浏览器、未切换人工页面、未修改标准组件或原批次统计。

## 诊断与修复

冻结 TripItineraryPlanner 的 dayCount 经外部 dayCountGetter/filter 隐藏 items；isConflict 经 isConflictGetter/indexOf 隐藏 computed conflictIds。旧只读 DAG 规则只处理根调用且不展开外部桥接函数，遗漏条件 class 和 s-if。新增边界内识别后，本步能映射文本、条件 class、s-if 共3个源码绑定。

共享 repair 规则按词法绑定、完整函数体、参数和只读调用图匹配，不按组件名。新 source_readonly_bridge_semantics.cjs 仅识别不可重新赋值、不可逃逸的顶层函数及精确循环形状；纯参数转发与有界尾转发可展开供分析。未知函数／效应、递归、传统回调、参数捕获、全局或循环遮蔽、缺失／冲突依赖、函数体／作用域漂移均不猜测放行。

旧循环不等价原生 filter/indexOf，稀疏数组会有差异。识别旧桥接仅授权从**源码**生成私有渲染副本；副本使用源码原生操作，不把旧循环当作等价证明。原公开方法、全部既有脚本 AST、其他调用者和 CSS 保留。新加两个私有方法，模板三个调用显式携带 items 或 conflictIds；computed 是依赖边界，本规则不证明其内部实现全面等价。已有显式公共图也需完整体证明；SeatBookingMap 的纯尾转发／提前返回经证明保留原字节，未按名称豁免。

修改位置：repair 的共享 AST 规则、已有校验器调用的分析函数、repair Prompt、独立候选门，以及 DOM 条件作用域映射。生成 Prompt、服务器和校验阈值未改。前处理、模拟模型返回的后处理、legacy profile 边界均有测试。

## 保护检查闭环

首轮 DOM 保护拒绝 s-if 改写造成的映射丢失，按设计阻断。现在 DOM 分析自己重新调用源依赖证明，只在私有函数体、显式参数和完整条件与源码匹配时使用源码条件签名；不更改实际模板、事件或偏移。条件下的事件缺陷仍报告，错误参数／函数体仍失去映射。候选门独立重算诊断和已证明绑定，拒绝反向退化、伪造 validation_passed 或清空错误列表；接受局部进展不代表整个组件通过。
