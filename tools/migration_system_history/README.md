# 实验历史诊断工具

这些脚本由原 `migration_system/scripts/` 移到实验工具区，代码保留，只调整系统定位路径。它们依赖历史冻结实验／旧格式任务证据，不是独立系统运行依赖，也不属于默认启动链。

实际系统入口仅为 `migration_system/scripts/run_system.py`；目录内的系统源码、Node 依赖、配置、数据库和产物均不再从此工具区加载。历史 Notebook 中旧命令是当时的记录，不回写为新位置。

若重新诊断旧任务，需根据它当时的产物根目录显式选择输入，不能将新系统 `var/artifacts` 的默认路径当成旧根目录下的实验结果。旧证据内封存的脚本字节和失败／费用记录不修改。本轮没有运行这些工具去覆盖原任务。
