1. 按 [系统指南](SYSTEM_GUIDE.md) 初始化新的独立数据路径、启动 API 和 `migration-worker`；不自动修改旧库。
2. 核对 TOML 模型、预算政策和浏览器配置，补齐对应终端环境变量；不在页面传模型凭据。
3. 核心运行配置完成后创建一条新的真实迁移任务，统一检查生成、校验、截图、修复、报告和下载；无需等可选训练／上传资源全部配置，也不用再逐模块反复交接。

新配置只用于新请求；不能改写旧请求的网络权限、Prompt 或绑定指纹来伪造已批准／已验证记录。
