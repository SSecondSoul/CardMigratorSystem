# San 业务实例契约 v1：保持迁移目标，不复刻 Vue

2026-11-17；契约标识 `san-business-instance-v1`。用户明确选择“保持 San 迁移目标”，采用此前方案 1。机器可读声明见 [契约 JSON](SAN_BUSINESS_INSTANCE_CONTRACT_V1.json)。

**这是经过用户确认的新验收范围，不是旧契约已经修好，也不是生产放行。** v1–v7 的原源码、失败报告、`arbitrary_public_key_contract_complete=false`、封存指纹及实验分母均保留。新报告须使用新契约标识，与旧口径分开，不回算旧通过率。

## 目标架构不变

Vue 源码 → 四维 SSM → San 组件 → 同口径静态／运行／结构／视觉／交互检查 → 规则或模型修复 → 复测和候选保护。

目标组件、DOM 渲染和事件入口仍是 San。不把原 Vue 源组件挂到目标页，不引入完整 Vue 组件／渲染运行时，也不新增要求用户提供互操作协议、状态白名单或手工编译元数据。必要的独立响应式内核可以复用，但必须在依赖及报告中披露，不能称为“零 Vue 依赖”。

## 任意业务键继续保留

- 所有 JavaScript PropertyKey：字符串、Symbol，以及通过原生 ToPropertyKey 转换得到的键；保留转换次序、次数和抛错。
- `extra.key`、`extra[key]` 等是**字面属性名**，不能当成 San Data 路径；Symbol 保留身份。
- `data`、`watch`、`dispose`、`attach` 等业务同名字段不能破坏原生 San 的 Data／生命周期。原生句柄由闭包持有，不暴露成可被业务覆写的魔法字段。
- stateKeys 只描述声明状态布局，不是外部可调用键白名单。未声明键遵循源实例上下文行为，不能为了更新界面而自动改成响应式声明状态。
- 对象、ref、别名、computed、props 只读及已捕获方法覆盖等已知行为仍需验证。不能仅支持当前源码用到的六个键，也不能限制成简单字符串／数值来判成功。
- Vue 预留公共属性保持其读取优先级、只读或赋值诊断；“任意业务键”不等于把 `$data` 等框架 API 改成普通业务字段。对预留键赋值与随后遍历私有实例图，是不同的行为。

## 公共行为仍属于修复范围

要求保留实际业务可观察行为，包括初始化、数据与 computed、动态父子 props、原生控件双向绑定、事件参数及 once／model 修饰策略、watch 清理与错误路由、nextTick／forceUpdate、生命周期及 DOM 可见性、keyed 身份和 scope 清理。

明确跟踪 `$data`、`$props`、`$attrs`、`$slots`、`$refs`、`$parent`、`$root`、`$el`、`$options`、`$emit`、`$forceUpdate`、`$nextTick`、`$watch`。**列入清单意味着必须实现或明确阻断，绝不代表目前全部已实现。** 业务使用的 slot／ref／选项结果仍需保留；不能以“不复制 vnode”为由免除公开功能。原来未支持的公开特性，也不能因此静默放行。

## 不再要求复制什么

不要求 San 目标复制 Vue 的私有 `$`／`_` 实例布局、vnode／subTree／patch flag、内部 effect／job／renderer 对象图或私有对象身份。这些不是本系统的目标产物。

但**排除私有结构等价，不等于批准依赖这些结构的源码**。若源码实际读取、写入或调用 Vue 私有运行时，必须诊断并在模型调用前按支持范围阻断；不能返回假的 vnode、空对象、undefined 或删掉相关语句来伪装成功。动态未知访问也不能仅凭“没看见私有名字”就证明安全。源动态 setter 本身不能简单等同为私有图遍历。

## 当前证据和真实剩余工作

v1–v7 的有限证据继续可参考，但不自动变成新契约通过：94 项原生对照、v7 4 项树场景、控件和调度都来自可信手工夹具，并非真实 SSM 编译／导出／加载成功。

以下仍需实现／验证，不能把它们重命名成“私有差异”而跳过：

1. 代理 child props 的动态传播及独立 watch／computed 更新。
2. 当前原型拒绝的 `$emit`／`$forceUpdate`，初始化 hook、事件／watch 错误路由等公共行为。
3. 源码／SSM 自动产生业务布局、原方法 receiver、San 导出与原生句柄加载，不再依赖探针手工传入 metadata。
4. 生成、规则／模型修复、独立验证器、候选回退和报告使用同一契约版本；新的实现／依赖指纹绑定到新产物。
5. 实际浏览器反例、独立部署及端到端回归；旧像素／DOM 阈值和表单状态检查保持。

因此契约声明本身只落实目标和版本化验收边界；生产仍保留 `source_dynamic_key_contract_unsupported`，不能把文档中的声明当作代码能力。本轮无模型调用、数据库变更或付费复跑，也无需因为这份契约重启服务器。

后续开发应连续补齐上述业务闭环，**不再优先扩建 Vue 私有 vnode／内部实例图模拟器**。已授权的业务 Proxy 是迁移实现手段，不是独立的跨框架互操作产品。
