这是未接入生产的研究修复，不代表完整任意公开键或真实组件已通过。

`native.json` 保存 94 个一致性场景及私有 vnode 图的实际未解决反例；`browser.json` 保存普通／ref 四页实际 DOM、pre/post 回调、嵌套别名及逃逸 ref；`controls.json` 保存 8 项边界控制。其余 5 文件为本轮研究实现和新增测试原文副本，以上 8 payload 由 SHA256SUMS.json 封存。

v1/v2 合并回归 13 项通过（32.993 秒，含原 v1 5 项），原公开键／控件 11 项通过（28.267 秒）；没有全量系统或模型批次复跑。内核是新增独立 @vue/reactivity 依赖，目标页没有 Vue 组件运行时，不宣称目标完全无 Vue 依赖。

源码副本保留原项目相对定位与依赖解释，不能直接在本归档目录执行。正常复现用 research/public_instance_v2 下脚本，先比较指纹；本包未包含全部操作系统、浏览器和依赖二进制，也不自动加载到 Worker。限制与中间失败详见 ../../PUBLIC_INSTANCE_PROXY_V2.md。
