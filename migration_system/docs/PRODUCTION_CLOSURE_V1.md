## 交付范围

只使用已有的一条主链：

可信本地 Vue 源码 → 源预检查 → 内置 AST／四维 SSM → 原实验 Prompt／few-shot → San → 静态语义、编译运行、AST／DOM、视觉及已配置交互 → 原规则／模型有界修复 → 同口径复测与候选保护 → 报告、SSM／San 下载和独立人工记录。

LangGraph 编排、持久化队列／检查点、调用收据和成本控制保持。目标仍是 San，不在 San 中挂载原 Vue 作为迁移结果；不引入新代理或改写已验证的内置引擎。独立运行指整个源码目录及其正常安装依赖，不是单独一个 wheel 或可搬移的虚拟环境。

## 当前源码与验收边界

| 项目 | 当前边界 |
| --- | --- |
| 输入 | 一个可信 UTF-8 Vue SFC，JavaScript Options API；当前导出入口接受 `export default` 和受限 `module.exports`；具体形式由预检查决定 |
| 样式与依赖 | CSS／scoped CSS；不支持外部源码依赖导入、script setup／TypeScript 和样式预处理器 |
| 动态公开实例键 | `this[key] = value` 的已识别任意公开键 setter 继续在模型前阻断；不缩小为固定键、不改源代码、不把它登记为通过 |
| 组件功能 | 预检查只排除已知不支持项，**不证明所有语义已支持**。slots、refs、父子事件等须根据实际源组件和场景检查，不能宣称全面兼容 |
| 自动通过 | 给定 props／动作下各质量维度满足原门槛；不等于任意输入与所有公共 API 等价 |
| 无交互配置 | `not_run`，不是交互通过；系统配置检查可能结束，但不能声称完整功能验收 |
| 修复 | 默认最多三轮，接受候选前复测；不得用更高视觉分抵消已通过功能的退化，不反复自动重发未知模型调用 |
| 部署 | 本机、可信源码、单用户；不宣称多租户隔离、互联网生产安全或论文效果指标已达成 |

对已知不支持输入明确终止；实际运行错误保留失败／诊断，不能因范围声明而豁免评估。门槛和失败样本分母不因本轮改判，支持性排除与迁移失败应单独披露，不能隐藏以提高成功率。
