## 后续 San 业务契约的实现增量（与上表生产复用分开）

用户选择保持 San 迁移目标后，新增 `runtime/san_business_v1`：复用 v7 已验证的响应式／owner 思路，分离并移除私有 vnode 模拟要求；目标仍由 San 渲染。源 Options 方法和 data() 通过自动 AST 编译绑定业务 Proxy，模板／样式取既有生成候选；不要求最终用户提供额外状态元数据。依赖固定的独立 @vue/reactivity／@vue/shared，并如实记录指纹。
