# 初始生成语法失败的闭环补齐（2026-11-17）

## 原任务与归因

任务 `b2a59e959191487fa4c3acbe945f04cb`，ExpenseTracker，原结果 `failed / repair_budget_exhausted`，实际模型调用 3 次，已知 Tokens 80802。原源码 SHA-256 为 `47995c773b5698e5f4fda5b5e854b27648c3b1e030a845ab19790930ad564736`。

初始生成有 10 条语法诊断；原第 1 轮规则修正两个循环，降为 4 条。随后两次模型候选仍有 4 条，均被拒绝；两次模型请求的 messages 相同。问题不是视觉分数或 Vue 源码错误，而是循环元素丢失、脚本多处标点损坏，以及拒绝后的反馈闭环缺口。3 轮额度包含规则轮，因此模型调用是一次生成加两次修复。

先用旧实现验证并复制 29 个任务文件和源文件，共 30 文件；证据在 `data/experiments/evaluator_calibration/2026-11-17_modular_expense_tracker_syntax_closure_v1`。所有新候选在独立证据目录生成，不改原 San、任务状态、数据库、Token 账本或用户配置。

## 修改范围

- `browser/target-syntax.mjs`：扩展有来源证明的语法正规化，不执行组件脚本。
  - 缺失 option：仅接受源中唯一对应的 option 叶节点；循环变量／集合／key／value／插值、祖先标签路径和 select 的 v-model 绑定必须匹配；不补其他属性、事件或未知作用域。
  - 方法分隔符：最多 4 个逗号，必须完整 Babel 重解析，并逐点证明相邻 ObjectMethod 边界；不能部分猜改脚本。
  - 简单叶方法：只支持受限调用／返回表达式和已声明状态读；只插入缺失右括号／右花括号，不改标识符、参数、常量或业务表达式。修复后必须是导出父组件的唯一方法，AST 与源导出的受限表达式相同。
  - 复杂方法：不翻译方法体；只允许补一个最后的右花括号，且完整方法 AST 与源中未改变的方法相同，无原始 Vue 状态访问。额外方法／属性、未知语法或整体解析失败均拒绝。
- `stages/syntax.py`、`application/migrations.py`：仍以已接受版本为修复父版本，最多附带 3 个同父版本被拒绝候选的哈希、拒绝原因、实际诊断和有限片段。候选／评估哈希不匹配则阻断。重复的完整修复 messages 在调用模型前阻断；未知调用的既有保护不变。
- 生成 Prompt 构造器和旧语义修复 Prompt 模板没有修改；语法专用消息补充失败反馈。常规语义修复消息也可附带同父版本的拒绝诊断。
- 修复预算、Token 停止线、评估阈值和候选保护标准不变；不把语法通过当成迁移通过。

## 语法解除后暴露的共享语义变体

初始生成不是先前手动选取的已修复候选；只有完整重放才能观察其后续缺口。本轮中间离线重放 `semantic_closure_v1` 的编译、结构、视觉和 15 步交互通过，但静态仍有 3 条，保留为失败证据，不写成闭环成功：

- 完整字符串样式 `{{'width: ' + size(amount) + '%'}}` 未被旧 CSS 包络证明识别。共享 `source_render_dependency_semantics.cjs` 现在仅投影单一已知尺寸属性、固定单位、三段表达式中的唯一方法调用，仍检查数值只读图、原公开签名及显式依赖；不忽略额外属性、单位或操作数差异。
- 非 San 的 `watcher:{...}` 不能等同于注册 watcher。共享 `source_phase_semantics.cjs` 只在源明确声明 `deep:true`、零参回调精确调用已声明方法、目标回调相同、没有既有注册或 watcher 反射、没有未知早期 hook，且启动调用与源 mounted 完全一致时，原子迁到 inited 注册，并让 mounted 动作在 attached 执行。浅层／默认 watcher、immediate、未知回调或启动效果不自动转换。
- 完整主路径还暴露了调度遗漏：`RepairStage._deterministic_repair_plan` 的有界语义入口条件没有覆盖 `missing_watch_migration` 和新增的 `source_watcher_option_not_landed`。已补齐映射，并添加“仅有 missing_watch 诊断也必须调用实际规则”的回归，避免只测试辅助函数而主流程不执行。中间 `semantic_closure_v2` 保留静态剩余 2 条的结果；不能用 helper 测试通过替代主流程通过。
